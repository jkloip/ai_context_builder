## 🎓 進階調教

### 參數說明

#### top_n（保留模組數量）
- **3-5**: 精準聚焦，適合明確的任務
- **8-10**: 全面分析，適合探索性任務
- **15+**: 大範圍搜集，適合複雜重構

#### lambda（相關性 vs 多樣性）
- **0.7-0.9**: 高相關性，少重複（任務明確時）
- **0.5-0.7**: 平衡模式（一般使用）
- **0.2-0.4**: 高多樣性，多角度（探索階段）

### 最佳實踐

✅ **DO（推薦）**
- 任務描述越具體越好，包含技術細節
- 啟用快取，調參時不用重複等待
- 定期更新排除清單，過濾無用目錄
- 大專案優先用 JSON 格式（更緊湊）

❌ **DON'T（避免）**
- 不要掃描系統目錄（如 C:/）
- 不要用空白或籠統的描述
- 不要忘記排除測試/遷移目錄
- 不要把 top_n 設太大（>20 通常無益）

## 🔧 故障排除

### 問題 1：找不到 Python
```bash
# 安裝 Python 3.8+
https://www.python.org/downloads/
```

### 問題 2：套件安裝失敗
```bash
# 升級 pip
python -m pip install --upgrade pip

# 手動安裝
pip install streamlit scikit-learn pandas
```

### 問題 3：沒有掃描到檔案
1. 檢查路徑是否正確
2. 確認資料夾有 `.py` 檔案
3. 查看是否被排除清單過濾

### 問題 4：掃描很慢
1. 檢查排除清單（是否排除了 `venv`, `node_modules`）
2. 啟用「使用快取」選項
3. 減少 top_n 參數

## 💡 實戰案例

### 案例：FastAPI 專案新增功能

**步驟**：
1. 專案路徑：`C:/projects/my_api`
2. 任務需求：
   ```
   新增 Stripe 支付整合功能，包含：
   - 創建支付 session API
   - Webhook 處理支付成功/失敗
   - 資料庫記錄交易
   - 單元測試和錯誤處理
   ```
3. 參數：top_n=8, lambda=0.7
4. 格式：XML

**結果**：
- 掃描 200 個檔案，耗時 15 秒
- 篩選出 8 個最相關模組：
  - `api/payment.py`（現有支付相關）
  - `models/order.py`（訂單模型）
  - `database.py`（資料庫連線）
  - `config.py`（配置管理）
  - ...等
- 生成 3000 行 XML Context
- 貼給 Claude/GPT-5
- 10 分鐘內得到完整可執行的程式碼！
